# An LLM drafts Pending interactions under guardrails

Matching Food names and Aliases against label text finds candidate pairs, but most matches are noise ("benzyl alcohol", "no clinically significant food effect"), and writing the summary, advice, Effect and Mechanisms for each one by hand would be the bottleneck. So the curation pipeline uses an LLM to discard non-interactions and draft the rest. Because this is a public medical reference, the drafts carry guardrails: the LLM only *suggests* a Severity and the reviewer sets it from the primary Citation; every draft must quote a short excerpt that the pipeline verifies is a verbatim substring of the label or abstract it came from, or the draft is dropped; excerpts appear only in the PR description, never in `data/`; and nothing reaches people without a human reviewing it in a PR (see ADR 0002). We rejected deterministic stubs only (too slow to fill) and unguarded LLM drafting (plausible but invented text on a medical site).
